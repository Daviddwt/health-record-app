## 1. 项目概述

### 1.1 项目名称
**健康档案小程序** (Health Record Mini Program)

### 1.2 项目定位
AI 驱动的个人健康档案管理工具，通过智能图片识别技术，帮助用户便捷地记录、整理和管理医疗就诊记录、用药清单和化验指标数据。

### 1.3 核心价值
- 📷 **AI 智能识别**: 拍照上传医疗单据，自动提取关键信息
- 📊 **结构化存储**: 数据自动同步到 Notion 数据库，支持多维度查询
- 📱 **移动优先**: H5 响应式设计，支持手机和桌面浏览器访问
- 🔒 **隐私保护**: 数据存储在用户自己的 Notion 空间，完全可控

### 1.4 目标用户
- 需要长期管理个人健康数据的普通用户
- 慢性病患者（需要定期记录用药和化验数据）
- 有老人/小孩需要照顾的家庭成员
- 医疗从业者（个人病例管理参考）

### 1.5 项目状态
| 模块 | 状态 | 完成度 |
|------|------|--------|
| 前端 H5 | ✅ 开发中 | 85% |

## 2. 产品背景

### 2.1 痛点分析

#### 用户痛点
1. **医疗单据易丢失**: 化验单、病历、处方等纸质单据容易丢失或损坏
2. **信息分散难整理**: 不同医院、不同时间的就诊记录分散，难以统一管理
3. **数据查询困难**: 需要查找历史化验结果或用药记录时，翻找纸质单据耗时
4. **手动录入繁琐**: 手工记录医疗数据耗时且容易出错

#### 现有解决方案不足
- **医院 APP**: 只能查看单一医院的记录，无法跨医院整合
- **电子健康卡**: 功能有限，不支持个性化记录和管理
- **手工记录**: 效率低，难以结构化查询和分析

### 2.2 产品愿景
让每个人都能轻松管理自己的健康档案，通过 AI 技术降低记录门槛，让健康数据真正为用户服务。

### 2.3 项目起源
- **发起时间**: 2026-02-23
- **发起人**: 秦哥
- **开发助手**: 小甲 (OpenClaw AI 助理)
- **技术选型原因**: 
  - Notion: 灵活数据库、免费额度充足、API 完善
  - AI 识别: 阿里云 Qwen-VL 视觉模型，医疗文书识别准确率高
  - H5 前端: 开发快速、跨平台、无需应用商店审核

## 6. 功能详细说明

### 6.1 AI 图片识别功能

#### 6.1.1 支持文档类型
- 化验单/检查报告
- 门诊病历
- 诊断证明
- 处方笺
- 出院小结

#### 6.1.2 识别流程
```
1. 用户选择图片 (拍照或相册)
   ↓
2. 前端上传图片到后端 /api/upload-and-analyze
   ↓
3. 后端保存到本地 /uploads/images/
   ↓
4. 调用阿里云 Qwen-VL API 分析图片
   ↓
5. 解析 AI 返回的 JSON 数据
   ↓
6. 返回结构化数据给前端
   ↓
7. 前端展示识别结果，用户确认后保存
   ↓
8. 数据同步到 Notion 数据库
```

#### 6.1.3 识别字段
```json
{
  "documentType": "文档类型",
  "hospital": "医院名称",
  "date": "就诊日期",
  "department": "科室",
  "patientName": "患者姓名",
  "chiefComplaint": "主诉",
  "diagnosis": "诊断结果",
  "testItems": [
    {
      "itemName": "项目名称",
      "result": "结果值",
      "unit": "单位",
      "referenceRange": "参考范围",
      "abnormal": true/false
    }
  ],
  "medications": [
    {
      "drugName": "药品名称",
      "dosage": "剂量",
      "frequency": "用法用量"
    }
  ],
  "doctorAdvice": "医嘱"
}
```

#### 6.1.4 识别准确率
- 化验单：约 85-90%
- 病历文书：约 80-85%
- 处方笺：约 75-80%

**注意**: 识别结果需要用户确认和修正，AI 仅作为辅助工具。

### 6.2 文件上传功能

#### 6.2.1 支持文件类型
| 类别 | MIME 类型 | 最大大小 |
|------|----------|----------|
| 图片 | JPEG, PNG, GIF, WebP | 50MB |
| 音频 | MP3, WAV, OGG, M4A | 50MB |
| 文档 | PDF, DOC, DOCX, TXT | 50MB |

#### 6.2.2 上传接口
```
POST /api/upload/:category?
Content-Type: multipart/form-data

参数:
- file: 文件对象 (必填)
- category: 文件分类 (可选，默认 documents)
  - images: 图片
  - audio: 音频
  - documents: 文档

返回:
{
  "success": true,
  "data": {
    "url": "http://141.148.169.133:3001/files/images/xxx.jpg",
    "filename": "uuid.jpg",
    "originalName": "original.jpg",
    "size": 102400,
    "category": "images",
    "uploadTime": "2026-03-15T06:00:00.000Z"
  }
}
```

#### 6.3.1 数据库配置

## 10. 部署说明

### 10.1 环境要求

**服务器**:
- 操作系统：Ubuntu 20.04+
- Node.js: 16+
- 内存：≥ 2GB
- 存储：≥ 10GB
- 网络：公网 IP

**第三方服务**:
- Notion API Key
- 阿里云 DashScope API Key (Qwen-VL)
- GitHub 账号

### 10.2 安装步骤

#### 10.2.1 克隆项目
```bash
git clone https://github.com/Daviddwt/health-record-app.git
cd health-record-app
```

#### 10.2.2 安装后端依赖
```bash
cd backend
npm install
```

#### 10.2.3 安装前端依赖
```bash
cd ../frontend
npm install
```

#### 10.2.4 配置环境变量
创建 `backend/.env` 文件:
```env
# Notion API 配置
NOTION_API_KEY=your_notion_api_key

# 阿里云 DashScope API Key
DASHSCOPE_API_KEY=sk-xxx

# 服务器配置
PORT=3001
UPLOAD_PORT=3001

# 公网访问地址
PUBLIC_URL=http://your-server-ip:3001
```

#### 10.2.5 启动服务

启动后端:
```bash
cd backend
node server.js
```

启动前端 (新终端):
```bash
cd frontend
node server.js
```

#### 10.2.6 访问应用
- 前端：http://your-server-ip:8888
- 后端 API：http://your-server-ip:3001

### 10.3 生产环境部署

#### 10.3.1 使用 PM2 管理进程
```bash
# 安装 PM2
npm install -g pm2

# 启动后端
cd backend
pm2 start server.js --name healthapp-backend

# 启动前端
cd frontend
pm2 start server.js --name healthapp-frontend

# 查看状态
pm2 status

# 设置开机自启
pm2 startup
pm2 save
```

#### 10.3.2 Nginx 反向代理
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /api/ {
        proxy_pass http://localhost:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

#### 10.3.3 HTTPS 配置 (Let's Encrypt)
```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```
